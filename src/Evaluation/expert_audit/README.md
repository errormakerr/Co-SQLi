# SQLi Expert Audit — local annotation web app

Quiz-style UI for the 3-question expert worksheet (Q1 / Q2 / Q3) used to
compute D3 (label correctness), D4 (α̂ ambiguity ratio + accuracy
ceiling), and D5 (attack-type precision) on the 4 benchmark datasets.

- 4 datasets × 250 stratified samples + 19 calibration = **1019 samples**
- SQLite persistence, resumable per-expert (token-gated)
- Auto-scored pairwise Cohen's κ and α̂ via `expert_audit_aggregator.py`
- Single-machine deploy; share remotely via `cloudflared`

## 1. Build the sample DB (one-time)

```bash
cd D:\project\server\SQLI\src\Evaluation\expert_audit
python expert_audit_sampler.py          # creates expert_audit.db
# or: python expert_audit_sampler.py --force   # wipe + rebuild
```

## 2. Configure

All settings live in `.env` — you do **not** need to export env vars each
launch. A default `.env` is already shipped; edit it once:

```dotenv
EXPERT_AUDIT_ADMIN_KEY=letmein         # change before sharing the tunnel
EXPERT_AUDIT_HOST=0.0.0.0
EXPERT_AUDIT_PORT=8000
EXPERT_AUDIT_RELOAD=false
EXPERT_AUDIT_LOG_LEVEL=info
```

`.env.example` is a documented template; copy it to `.env` if you ever
want to reset the file. A real shell env var (if set) still overrides
`.env`, so CI/CD overrides work as expected.

## 3. Start the server

```bash
# install once
python -m pip install fastapi "uvicorn[standard]"

# run — reads .env, binds HOST:PORT
python run.py
```

Open <http://localhost:8000> for the expert UI,
<http://localhost:8000/static/admin.html> for the admin console.

## 4. Share with remote experts

Use a cloudflared "quick tunnel" — no account needed:

```bash
# one-liner; prints a https://*.trycloudflare.com URL
cloudflared tunnel --url http://localhost:8000
```

Send each expert the HTTPS URL plus a unique token string (any
memorable string). Their progress is keyed on that token, so they can
close the tab and resume later by re-entering the same token.

## 5. Expert worksheet

| Q | Question | Answer set |
|---|----------|-----------|
| Q1 | What is this SQL? | `mal` / `ben` / `ambiguous` / `invalid` |
| Q2 | Could some realistic schema flip the verdict? (only if Q1 ∈ {mal, ben}) | `yes` / `no` |
| Q3 | Attack class(es) — multi-select (only if Q1 = mal) | tautology / boolean / union / error / time / stacked / inline / other |

Keyboard shortcuts: `1/2/3/4` → Q1, `y/n` → Q2, `Enter` → submit.

## 6. Aggregate results

Once all experts have finished (or whenever you want an interim look):

```bash
python expert_audit_aggregator.py
```

Writes:
- `../reports/expert_audit_summary.json`
  — per-dataset α̂ + 95% CI + T₁ accuracy ceiling 1 − α̂/2
  — per-dataset label-correctness rate + CI (D3)
  — D5 auto-classifier precision TP/FP vs expert Q3
  — pairwise Cohen's κ on Q1 across experts
- `../reports/expert_audit_disagree.jsonl`
  — one row per sample where ≥ 2 experts disagreed on Q1
    (forwarded to an arbiter for tie-break)

## 7. Calibration gate

The first **19 calibration samples** (5 per dataset, 1 was deduped)
come up at the start of each expert's queue. Use their Q1 agreement
to compute κ before opening the main 1000 samples — we recommend
κ ≥ 0.7 before trusting the full batch.
